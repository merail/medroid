# Medroid — идеи и план развития

Medroid задуман как приложение для Android-разработчиков: быстро найти техническую информацию об устройстве и иметь под рукой полезные утилиты, которых нет в стандартных «Настройках».

Каждая утилита — отдельная пара модулей `<feature>/api` + `<feature>/impl` (см. CLAUDE.md), `app` только подключает их в навигацию.

## 2. Переключатели режима разработчика (новый модуль)

Требуют `android.permission.WRITE_SECURE_SETTINGS`. Обычному приложению его не выдать, но у разработчика есть adb, и разрешение выдаётся один раз (сохраняется после перезагрузок и обновлений, сбрасывается при удалении приложения):

```bash
adb shell pm grant merail.tools.medroid android.permission.WRITE_SECURE_SETTINGS
```

Приложение проверяет `checkSelfPermission` и, если разрешения нет, показывает эту команду с кнопкой «Скопировать».
